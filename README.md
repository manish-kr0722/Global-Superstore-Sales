# Global Superstore Sales & Profitability Dashboard

# Project Overview

This project presents an interactive Power BI dashboard built to analyze the sales, profitability, product performance, customer segments, returns, and geographic performance of a global superstore.

The project focuses only on dashboard development and data visualization in Power BI. It contains two report pages: Overview and Demographic.

# Dashboard Pages

1. Overview

The Overview page provides a high-level summary of overall business performance through:

Top 5 products by quantity sold

2. Demographic

The Demographic page presents the geographic distribution of sales through:

Global sales map

Top 5 regions by sales

Loss-making regions

KPI cards for overall business performance

# Key Dashboard Insights

The Consumer segment generated the highest sales at approximately 6.51M.

Technology was the leading category, contributing approximately 4.7M in sales.

Asia Pacific was the strongest market, with approximately 4.0M in sales.

Phones were the highest-selling sub-category, generating approximately 1.71M.

Western Europe was the top-performing region, with approximately 1.73M in sales.

Western Asia and Western Africa were the largest loss-making regions.

The business achieved an overall profit margin of 11.61% with a return rate of 4.19%.

# Interactive Features

Year filter for 2012, 2013, 2014, and 2015

Page navigation between Overview and Demographic views

Cross-filtering between visuals

Geographic analysis using an interactive map

Consistent dark theme with category-based color highlights
